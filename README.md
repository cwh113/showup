# Show Up

A one-tap morning workout app for Chris. It follows the 7-day plan from Google Calendar
(Other Calendar → "Day 1–7") and ramps up to it in four stages, moving up only when the habit is holding.

**Cue:** after I brush my teeth → gym clothes → Rafter gym → shower → coffee.

- Streaks with freezes, milestones, daily quests, XP, surprise chests, comeback bonus
- Guided sets with rest timer, interval timer and mobility flow
- Optional Oura connection (readiness, sleep, resting HR, HRV, logged workouts)
- Data stays in this browser; Export/Import JSON in Settings

Live at https://cwh113.github.io/showup/ (add to Home Screen from Safari).
